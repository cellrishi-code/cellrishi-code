## 🚀 Featured projects

### 🧰 [Claude Skills Atlas](https://github.com/cellrishi-code/claude-skills-atlas)
An open-source, community-driven collection of reusable AI skills, prompts, workflows, agent definitions, templates, and integrations. The goal: make useful resources for AI-assisted development easier to discover, reuse, and improve.

### 🌪️ [Indian Cyclone AI Weather Lab](https://github.com/cellrishi-code/SIH-FINAL-PROJECT-70)
A research prototype for exploring North Indian Ocean tropical cyclones. Includes historical track data, statistical forecasting baselines, held-out-season evaluation, and a FastAPI service. Neural forecasting models are still untrained, so implemented results and planned work are kept clearly separate.

### ✨ [Lumex AI](https://github.com/cellrishi-code/Lumex-AI)
An AI and data-focused project exploring ways to turn complex datasets into useful analysis and insights.

### 🦀 [Rustalis](https://github.com/cellrishi-code/Rustalis)
An experimental Rust-first operating-system project targeting x86_64. Work includes the `no_std` kernel foundation, bootloader integration, serial logging, and a QEMU development workflow—with kernel subsystems growing step by step.

### 📚 [Saarthi](https://github.com/cellrishi-code/Saarthi)
An academic resource platform that organizes learning materials by department, semester, and course to make student resources easier to find.
