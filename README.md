## Featured work

### [Claude Skills Atlas](https://github.com/cellrishi-code/claude-skills-atlas)
An open-source, community-driven library of reusable AI skills, prompts, workflows, agent definitions, templates, and integrations. The project aims to make practical resources for AI-assisted development easier to discover, reuse, and improve.

### [Indian Cyclone AI Weather Lab](https://github.com/cellrishi-code/SIH-FINAL-PROJECT-70)
A research prototype for exploring North Indian Ocean tropical cyclones. It includes historical track data, statistical forecasting baselines, evaluation on held-out seasons, and a FastAPI service. Neural forecasting models are still untrained; the project distinguishes implemented measurements from planned work.

### [Lumex AI](https://github.com/cellrishi-code/Lumex-AI)
An AI and data-focused project exploring tools for turning complex datasets into useful analysis and insights.

### [Rustalis](https://github.com/cellrishi-code/Rustalis)
An experimental Rust-first operating-system project targeting x86_64. Work includes the `no_std` kernel foundation, bootloader integration, serial logging, and a QEMU development workflow, with kernel subsystems developed incrementally.

### [Saarthi](https://github.com/cellrishi-code/Saarthi)
An academic resource platform that organizes learning materials by department, semester, and course for students.

### [Scientific computing and ML notebooks](https://github.com/cellrishi-code?tab=repositories)
A collection of experiments and learning projects covering unsupervised learning, neural networks, dimensionality reduction, numerical simulation, and algorithms.
